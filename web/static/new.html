提交一组基因做富集分析

粘贴基因符号（每行一个，或用逗号、空格分隔），选择物种与注释来源。 提交后会生成一条运行记录，包含输入哈希、参数与完整审计轨迹。

提交后任务进入本地队列，由后台 worker 调用 g:Profiler REST API 完成富集分析（通常 1～3 秒）。原始请求与响应会完整保存，便于复核。 打开结果页后会自动刷新到分析完成。

当前阶段的实际行为
1 · 校验与入库
服务端重新校验基因符号、去重、计算输入哈希，并写入运行记录。
2 · 入队与执行
任务状态从「排队中」变为「运行中」，worker 用一次 HTTP POST 调用 g:Profiler，并受超时与重试策略约束。
3 · 结果、溯源与报告
返回的条目按上游数值原样入库，同时保存原始 JSON、数据源版本与 HTTP 状态；报告可下载为 Markdown。
